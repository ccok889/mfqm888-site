模仿笔迹 SEO 纯静态网站示例
============================

打开方式：直接双击 index.html 即可查看首页。

页面结构：
- index.html：首页
- category/mofang-biji.html：列表页
- category/mofang-qianming.html：模仿签名栏目页
- category/biji-jianding.html：笔迹鉴定栏目页
- case/index.html：案例展示页
- case/shanghai-handwriting.html：上海模仿笔迹案例详情
- case/business-signature.html：商务签字案例详情
- case/document-comparison.html：手写文件对比案例详情
- case/personal-font.html：个人手写字体案例详情
- news/index.html：资讯中心页
- contact/index.html：联系我们页
- search.html：独立搜索结果页
- article/shanghai-mofang-biji-price.html：价格详情页
- article/mofang-biji/：模仿笔迹独立文章（5篇）
- article/mofang-qianming/：模仿签名独立文章（5篇）
- article/biji-jianding/：笔迹鉴定独立文章（5篇）
- article/city/：城市资讯独立文章（1篇）
- city/shanghai/index.html：上海城市页
- assets/css/style.css：全站样式
- assets/css/reference.css：参考图紧凑版视觉样式
- assets/js/main.js：清晰的移动导航与站内搜索
- assets/images/：首页横幅、模仿签名、手写文件、手写笔迹配图
- search.json：静态搜索索引
- robots.txt / sitemap.xml：SEO 基础文件
